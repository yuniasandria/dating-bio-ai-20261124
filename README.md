## The bio

> No sleep, no exes, no baggage. Just me, awake at 3am, rereading your last message for the 400th time. Swipe right if that's romantic and not alarming.

150 characters — inside the 180-character limit.

## How it works

`main.ts` (Node 22+, TypeScript run as-is) writes the bio line, byte-identical
on every run, to `/output/entry.txt`, where the sealed scorer gates it
(UTF-8 text, 1 to 180 characters). It also prints the line to stdout.

```sh
node main.ts
```
